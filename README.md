# State

This is a pedagogical exercise to construct the foundations of math (or at least basic arithmetic) from nothing more than encapsulation (i.e. a Python class which can either hold nothing or an object of its own class). No loops, no numbers, no foundational types except for `State`. If statements are used, but only to discern whether something is `None`.

The idea here is to frame the foundations of mathematics as 'difference within the same'
